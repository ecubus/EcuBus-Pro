# 面板

## 自由布局面板

在 Panel 菜单中新建面板，把控件拖到画布上，在属性编辑器中配置绑定。可使用分组、标签页、对齐、缩放和撤销/重做来排布界面。编辑器预览用于检查布局；启动测量后在运行视图中与变量和信号交互。

布局保存为 `.ecpanel` 文件，`.ecb` 工程只保存文件引用，分享时需同时提供两个文件。可导入已有 `.ecpanel` 复用布局；文件移动后可重新选择文件，重新关联时使用所选文件中保存的名称。工程中嵌入的旧版面板若全部项目都受支持，打开时自动转换；否则编辑器显示迁移报告，并把已转换的控件另存为新的 `.ecpanel` 副本。

示例见 `resources/examples/panel_showcase/PanelShowcase.ecb`，独立 HTML 示例位于 `resources/examples/panel_html`。

## 记住值

写入用户变量的控件默认开启“记住值”。停止测量时，变量的最后一个值写回工程，保存工程后写入 `.ecb`，下次启动测量沿用该值。关闭后，每次启动测量使用控件的“初始值”（默认 0，输入框和路径控件默认为空文本）。多个控件写同一变量时，只要有一个关闭，就使用该控件的初始值。

只保存 Panel 控件写入的用户变量，系统变量和 CAN/LIN 信号值不保存。CLI 使用 `.ecb` 中保存的值启动，不应用 Panel 初始值。

Panel 的“打开文件”按钮仅支持目录及 PDF、TXT、Markdown、CSV、PNG、JPEG、GIF、BMP、WebP 文件，不允许直接打开程序、脚本或快捷方式。

## HTML 信号读取

`getSignal()` 返回当前测量中最近解析的发送或接收报文样本，不依赖 HTML 订阅；没有样本时回退到工程数据库中的已有值，可能为空。`setSignal()` 更新发送数据库，成功返回不代表报文已发送或 ECU 已处理，因此紧接着调用 `getSignal()` 不保证读到刚写入的值。缓存从测量开始持续记录，以保留首次读取或打开独立窗口之前出现过的单次报文。

## 面板功能

面板功能为快速构建各种演示或测试平台提供了卓越的灵活性：

- 为具有图形界面的用户创建转换工具
- 为生产线工人构建具有简单、基于点击界面的测试流水线
- 将组件连接到 DBC/LDF 文件信号，使 UI 更改能够触发相应的信号更改，请参阅 [数据库](./../database)
- 将组件绑定到用户定义或系统变量以显示或修改其值，请参阅 [变量](./../var/var)
- 还有更多功能等待您发现！
